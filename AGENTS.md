# Working rules

- Always work on a feature branch. Before editing files, create or select a branch for the task. Use `feature/<short-description>` for new branches.
- Ask the user for explicit approval before every commit, every push, and every PR creation. This includes pushes that update an existing PR. Show the proposed changes and intended action before asking. Approval applies only to the stated action. Obtain approval for each action when requesting several together.
- Include these rules in every subagent assignment. The coordinator owns commits, pushes, and PR creation and obtains the user's approval before performing them.
